Canonical API 契约

页面只调用这一套资源路径；P20 不重复实现买入、Quote、Swap 或离场接口，交易继续复用 P19。

统一响应

所有新 P20 API 使用同一 envelope，错误包含稳定 code，页面不解析自由文本判断状态。

{ ok: true, data }成功结果
{ ok: false, error, code }可处理错误
