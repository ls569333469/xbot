P12 架构治理、重试内核与 Robinhood

执行顺序固定为 P12-A 收敛 Chain/Provider 边界、P12-B 落地统一重试内核、P12-C 接入 Robinhood。Robinhood 是 GMGN 已支持的 EVM 链，不是独立交易 Provider；Binance 仅能补充已上币现货，不能替代 Robinhood 链上 CA 交易。
