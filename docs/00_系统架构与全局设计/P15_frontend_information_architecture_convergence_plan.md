# P15 前端信息架构与配置收敛方案

> 状态：已完成正式实施与最终回归验收。
>
> 目标：把 XBOT 从“后端字段的可视化控制台”收敛为面向真实交易任务的产品界面。

## 1. 本次审计结论

当前主要问题不是配色或间距，而是控制权和信息架构错误：

1. 设置页同时承载日常交易、一次性链验收、实时诊断、底层参数和密钥管理。
2. 后端每增加一个能力，前端就在页面末尾增加一张卡片，缺少固定页面归属。
3. “明确失败重试”直接暴露链级实现字段，要求用户理解次数、窗口、费用包络和 Gas Reserve。
4. “自动交易范围”重复展示白名单数据；真正的维护入口已经在白名单页。
5. Robinhood 已完成生产批准，但一次性验收控制仍长期占据默认设置页。
6. GMGN 调度、缓存、429、P0-P4 队列属于运行诊断，不属于用户设置。

## 2. 前端产品标准

### 2.1 一个用户决策，只保留一个控制

- 二元决策使用一个开关，不再增加链标签、输入框和保存按钮。
- 链差异、限流参数、证据窗口和费用计算由后端 Chain Manifest 管理。
- 前端只展示结果、影响和异常，不复制后端默认值。

### 2.2 页面按任务分层

设置页固定为三个视图：

| 视图 | 用户任务 | 内容 |
| --- | --- | --- |
| 交易 | 决定系统如何自动交易 | 真实交易启停、明确失败自动重试、自动交易范围摘要 |
| 运行状态 | 判断系统是否健康 | GMGN、6551、链状态和异常；正常指标折叠 |
| 系统维护 | 维护连接与凭据 | API Key、RPC、数据库和管理员口令 |

默认进入“交易”。单个视图最多三块一级内容，不允许继续向页面底部追加功能卡片。

### 2.3 渐进披露

- 默认只显示用户需要立即判断的状态。
- 正常运行时隐藏调度器权重、心跳毫秒数、缓存批次等诊断字段。
- 出现异常时，在“运行状态”中显示原因和处理入口。
- 一次性验收完成后从前端完全退出，后端能力登记到维护工具清单。

### 2.4 配置所有权

- 白名单拥有 CA、链、金额、次数、滑点、止盈止损和关系事件。
- 设置页不得再次维护上述字段，只显示白名单派生摘要。
- 后端拥有重试次数、链级时间窗、证据判定、费用升级和费用上限计算。
- 前端拥有“是否允许明确失败后自动重试”这一项用户决策。

### 2.5 新功能准入

新增功能在进入前端前必须回答：

1. 这是用户决策、运行状态，还是维护工具？
2. 是否已有页面拥有同一数据？
3. 能否由系统默认值自动完成？
4. 正常状态下是否需要一直可见？
5. 是否会让同一业务规则出现第二个配置入口？

无法明确归属的功能不得直接新增卡片。

## 3. 明确失败重试的新交互

前端只保留一个“失败后自动重试”开关：

- 开启：对所有已通过实盘验收的交易链生效。
- 关闭：所有链停止创建新的 Retry Attempt。
- 切换时明确提示会停止新的真实买入以应用配置。
- 状态不确定、429、鉴权失败、余额不足和参数错误始终不重试，此规则不可被前端关闭。

后端自动派生：

- 最大重试次数：由 Chain Manifest 管理，上限仍为 2。
- 重试有效窗口：按链默认值管理。
- 单次费用上限：使用该链现有 `GMGN_MAX_FEE_RESERVE_*`，不新增第二套资金参数。
- 退出 Gas 保留：使用该链现有 `GMGN_MIN_GAS_RESERVE_*`。
- 费用升级：只在 Adapter 已验证支持的链启用；Robinhood 不猜测费用字段。

## 4. 页面调整范围

### 4.1 交易视图

- 保留真实交易启停主控。
- 将明确失败重试改为单开关。
- 自动交易范围只显示数据源、链数、事件类型和有效 CA 数。
- 详细 CA 列表移回白名单页，通过“管理白名单”进入。

### 4.2 运行状态视图

- 合并 GMGN 与 6551 的正常状态摘要。
- 只突出断线、429 冷却、积压、失败事件和链不可交易。
- P0-P4 权重、缓存和时延分位数放入“诊断详情”，默认折叠。

### 4.3 系统维护视图

- API、RPC、数据库和口令按“接口授权 / 链连接 / 本地服务”分组。
- 新链诊断、限时验收和生产批准不提供前端入口，只保留受控后端接口。
- 生产链状态统一在“运行状态”显示；维护工具见项目级登记表。

## 5. 实施顺序

1. 评审独立 HTML 原型，确认页面归属和文案。
2. 后端新增统一重试开关 API，并复用现有链费用保护。
3. 前端切换为三个设置视图，删除逐链重试表单。
4. 收敛自动交易范围，并将新链验收操作退出前端。
5. 增加配置契约、前端 DOM 和移动端布局测试。
6. 保持所有链重试默认关闭；发布后由用户主动开启。

## 6. 验收标准

- 默认设置页首屏只出现一个主要交易控制和必要设置。
- 开启失败重试不要求填写任何技术参数。
- 白名单业务参数只有一个维护入口。
- 正常情况下不展示调度器、心跳和缓存内部参数。
- 桌面与移动端无横向溢出、控件重叠或文字遮挡。
- 前端构建、Lint 和后端完整测试通过。
- 正式实施前后，现有实盘开关和五链配置值不被自动改变。
